# Arena visual direction

The four supplied references establish three surfaces: a sparse two-seat table,
a dense hand-class matrix with action frequencies, and a restrained statistics
terminal. PokerZero uses those structures for an offline research workflow.

## Tokens

| Role | Value | Purpose |
|---|---|---|
| Graphite | `#0c1010` | Page ground |
| Panel | `#151b1a` | Controls and research records |
| Deep felt | `#132b25` | Only the play surface |
| Felt edge | `#3c584e` | Table boundary |
| Sage | `#8fc2a0` | Current action and positive emphasis |
| Warm linen | `#e8eee9` | Primary text |

Georgia gives the large headings a quiet editorial character; Arial keeps
controls and numeric evidence compact and legible. A tiny monogram appears on
the facedown card and brand mark. The table outline is the one visual gesture;
cards, pot, seats, and action state carry the page.

## Layout

```text
Desktop:  heading / status
          ┌───────────────────────┬──────────────┐
          │  heads-up table        │  action desk │
          └───────────────────────┴──────────────┘
          public action ledger

Study:    decision sequence
          ┌───────────────────────┬──────────────┐
          │  169 hand classes      │  real values │
          └───────────────────────┴──────────────┘

Research: cohort/provenance strip → full opponent table → source hashes
```

On narrow screens, columns stack, action targets retain 44 px minimum height,
tables scroll horizontally, and the hand matrix preserves all 169 cells.
Focus remains visible and nonessential transitions stop under reduced motion.

## Evidence rules

The matrix has neutral cells until a real class-level policy snapshot exists.
Recorded action probabilities appear only from completed hand diagnostics.
The research ledger reads an existing local report without writing it; missing
reports and missing diagnostics are labeled unavailable. No win rate, GTO score,
equity, or strategy frequency is generated by the frontend.
